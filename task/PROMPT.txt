实现离线安全事件重建工具，输入来自三台模拟主机的签名事件文件及采集清单，不联网采集真实设备。

请从空目录实现以下可运行工具。环境为 Windows、Python 3.12、仅CPU；不使用Docker或真实外部服务。除题面明确允许的cryptography外只用标准库。输入样例、模拟组件和测试数据由你在项目内构造，不存在另行提供的附件。

核心要求：
1. 每条事件包含host、boot_id、seq、单调计时、墙钟时间及可选发送或接收message_id；主机时钟偏差由校准记录给出闭区间。把事件表示为可能UTC区间，同一boot内按seq排序，不同boot不能直接比较单调计时。
2. 利用发送先于接收、同主机顺序和校准区间约束推导偏序；无法确定先后的事件必须保留并发关系，不能强行按墙钟排出唯一真相。约束矛盾时返回一组最小不可满足核心，最小指删除其中任一约束后不再矛盾。
3. 输入文件逐字节哈希并保留行号和字节区间，事件去重只能合并内容完全一致的同ID记录；同ID异内容作为证据冲突。导出事件图、可行时间范围、冲突证据及确定性拓扑展示，不修改原始文件。

必须覆盖的验收场景：时钟回拨、重启、重复采集、发送接收矛盾和区间部分重叠；用小规模穷举或独立差分约束实现核对可行性，证明输入哈希前后一致。

交付源代码、README、样例及自动化测试。提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v 两个入口；cases.json可引用项目内源文件或二进制样例。输入输出schema、错误码及未写明的非安全性细节自行设计并完整说明，不能放宽上述要求。测试必须断言具体结果、状态或证据，不能只打印成功；固定种子可重放。所有操作局限在项目测试目录和本机模拟服务。
